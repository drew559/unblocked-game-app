# Neon Highway Rush

A simple, unblocked browser driving game built with HTML, CSS, and JavaScript.

## How to run

- Open `index.html` in any modern browser.
- Or serve the project locally with a static file server if you prefer.

## Controls

- Steering: A / D or Left / Right arrow keys
- Optional speed control: W / S or Up / Down arrow keys
- Restart: click the Restart button or press R

## Goal

- Avoid traffic and collect coins.
- Survive as long as possible and beat the high score.
